# Changelog

## 0.1.0 — 2026-10-28

Первая версия.

- Записи блога: список с постраничным выводом (`/blog/`) и страница записи (`/blog/{slug}`); текст в Markdown.
- Рубрики (`/blog/category/{slug}`) и теги (`/blog/tag/{slug}`); у записи одна рубрика и любое число тегов.
- Редактор в админке (меню «Блог»): создание, правка и удаление записей, рубрик и тегов; черновики;
  смена адреса рубрики/тега переносится в записи, удаление — снимает их с записей.
- Мультиязычность через плагин i18n (если установлен): поля на каждом языке сайта, адреса `/en/blog/…`,
  hreflang для переведённых записей, строки сайта переопределяются словарём i18n (`blog.*`).
  Без i18n — один язык.
- Данные в `plugin-data/blog/` (posts/categories/tags.json); повреждённый файл не перезаписывается.
- Лицензия MIT.
